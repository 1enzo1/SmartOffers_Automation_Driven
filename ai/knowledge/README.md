# Knowledge

Esta pasta sera usada para a ontologia SmartOffers e conhecimento de dominio.

No MVP7.6.1, ela e apenas um marcador estrutural.

## Conteudo futuro previsto

- cliente: `external_id`, `customer_id`, account, msisdn;
- campanha: `campaign_id`, `id_contract`, estado atual;
- evento: `event_id`, `ext_event_id`, `external_uid`, `consumer_id`, `subpartition_id`;
- metricas;
- caracteristicas;
- auditoria;
- processamento;
- NRT, Kafka, BKO, SmartGateway e ACM Query.

## Limites

Conhecimento de dominio nao deve conter secrets, hosts reais, IPs internos ou dados brutos de ambiente.
