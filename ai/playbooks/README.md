# Playbooks

Playbooks descrevem roteiros operacionais seguros para troubleshooting e validacao.

No MVP7.6.1, esta pasta e apenas contrato Markdown.

## Playbooks futuros previstos

- cliente nao entrou em campanha;
- SMS nao enviado;
- evento nao processado;
- callback nao refletiu;
- beneficio nao atualizou;
- publicacao de catalogo;
- BKO massivo;
- fila ou backlog NRT.

## Estrutura esperada

Cada playbook deve declarar:

- sintoma;
- hipoteses;
- evidencias seguras;
- queries de leitura planejadas;
- sinais de risco;
- proximos passos;
- o que nao fazer automaticamente.
